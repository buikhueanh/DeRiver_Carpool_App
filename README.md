# 🚗 DeRiver | DePauw Carpool App

A real-time carpooling platform built with Vue.js and Firebase, **designed to connect DePauw University students** for shared rides—solving transportation gaps in a cost-effective, community-first way.

https://github.com/user-attachments/assets/8a8d3357-0372-436b-b94a-faecc6e5ef4e

## 📌 Overview

**DeRiver** empowers students without personal vehicles by matching them with peers who have cars. The platform enables seamless trip coordination, transparent communication, and real-time updates—all within a responsive, mobile-friendly interface.

> “Getting home for the weekend or attending off-campus events shouldn't be a barrier. DeRiver bridges that gap.”  

---

## ⚙️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **Vue.js** | Developed a responsive, single-page frontend with clean UI/UX |
| **Firebase Realtime Database** | Enables instant ride posting, ride requests, and data sync |
| **Firebase Auth** *(optional)* | Secures user sessions (for future iterations) |

---

## 🚀 Features

- 🧭 **Post & Browse Rides:** Drivers can offer trips; riders can request or join.
- 🔄 **Real-Time Syncing:** No page reloads needed—new rides appear instantly.
- 🔒 **Access Control:** Only authenticated users can coordinate rides (optional).
- 📱 **Responsive Design:** Web experience for students on-the-go.
- 💬 **Chat Functionality** *(planned)*: Enabling riders and drivers to connect securely.

---

## 🎯 Problem Solved

> Many DePauw students lack reliable transportation for breaks, groceries, or social events. DeRiver reduces student isolation and transportation stress through peer-to-peer sharing—building trust and convenience into every ride.
